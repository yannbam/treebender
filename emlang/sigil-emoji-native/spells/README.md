## What Makes This Native?

This spell library uses **emoji AS the language** - not text representations!

**Text Version** (sigil-emoji/):
```
eye langle fire rangle
```

**Native Version** (sigil-emoji-native/):
```
👁️ ‹ 🔥 ›
```

The emoji are actual terminals in the grammar. You can copy-paste them, type them directly, and see meaning embodied in visual form!

## 🌈 The Hybrid Philosophy in Action

### Emoji for Semantic Markers

These carry MEANING:
- **Evidentials**: 👁️ 🔍 👂 🔮
- **Honorifics**: 🙇 😐 🙏 👑
- **Directions**: ⬆️ ⬇️ ⏺️ 💫 ⭕
- **Elements**: 🔥 💧 💨 🪨 ⚫
- **All other markers**: 🔁 ✅ 🌿 🧠 🤔 ⚡ 👥 etc.

### Unicode for Structural Delimiters

These organize STRUCTURE:
- **Amplify**: ‹ › (Unicode single angle quotes)
- **Stabilize**: ⟦ ⟧ (Unicode double brackets)
- **Transform**: ❴ ❵ (Unicode ornate braces)
- **Channel**: ⦅ ⦆ (Unicode double parentheses)

### Words for Operations

These perform ACTIONS:
- **Fusion**: `plus`
- **Subtraction**: `minus`
- **Alternative**: `or`

**Why?** Each tool serves its purpose. Emoji shows meaning, Unicode shows structure, words show operations. This isn't compromise - it's optimization!

```

```


## 🎪 Advanced Topics

### Unicode Normalization

Emoji can have multiple representations:
- Simple: `🔥` (single codepoint)
- With variation selector: `👁️` (base + VS-16)

Treebender handles both correctly as it processes UTF-8 strings.

### Ambiguity with Native Emoji

```
👑 ‹ ❴ ⚫ plus ❴ 🔥 plus 💧 ❵ ❵ ›
```

Still produces 4 parses (same as text version) because ambiguity is structural, not lexical!

### Container Paradoxes

```
‹ ⟦ 🔥 ⟧ ›
# Amplified stabilized fire
# Stabilizer forces energy: low
# Amplifier increases power
# Both coexist in parse tree!
```
