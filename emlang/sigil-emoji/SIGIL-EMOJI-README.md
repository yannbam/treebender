## 🔧 Implementation Notes

### Token Mapping
The grammar maps emoji-friendly names to treebender:

```fgr
Evidential[ evid: direct ] -> eye       // 👁️
Evidential[ evid: inferred ] -> mag     // 🔍
Honorific[ honor: sacred ] -> crown     // 👑
Animacy[ anim: sentient ] -> brain      // 🧠
```

### Feature Unification
All features from ULTRA are preserved:
```
eye bow up langle fire rangle

Parses to:
Sigil[
  evid: direct       (👁️)
  honor: humble      (🙇)
  direction: upward  (⬆️)
  Container[
    type: amplify
    Element[type: fire, energy: high]
  ]
]
```

### Unicode Support
Treebender handles this naturally:
- Input tokens: `eye`, `bow`, `fire`
- Display: Add emoji in docs/UI
- Future: Could accept actual emoji as tokens! 🎉
