# Test Suite: Composition Operator (∘)
# Pure grammar implementation creating first-class composed transformers
# Mathematical function composition: (f ∘ g)(x) = f(g(x))
#
# Syntax: transformer1 compose transformer2 apply <target>
# Semantics: Right-to-left application (compose f g = first g, then f)
#
# Difference from ComposedTransform:
# - ComposedTransform (🔄 📦 🔥): direct sequential application
# - Composition operator: creates REUSABLE composed transformer
#
# Available transformers:
# 🔄 recursion, 🎭 morph, 🧬 replicate, 📦 package
# 🔗 bind, ⚡ force, 🌀 lazy, 🪞 reflect
