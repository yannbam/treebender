## The 10 Exotic Systems

### 1. 🔍 EVIDENTIALITY
**"How do you know this?"**

Inspired by: Turkish, Quechua, Bulgarian, Tuyuca, Georgian

Many languages require you to mark HOW you know something:

| Marker | Feature | Meaning | Real Language Example |
|--------|---------|---------|----------------------|
| `vis` | `evid: direct` | "I saw it myself" | Turkish `-DI` (direct past) |
| `inf` | `evid: inferred` | "I infer from evidence" | Quechua `-shka` (inferential) |
| `her` | `evid: hearsay` | "I was told/tradition says" | Turkish `-miş` (reported) |
| `int` | `evid: intuitive` | "I sense/feel it mystically" | Novel (spiritual knowing) |

**Examples:**
```
vis langle asterisk rangle
"I DIRECTLY WITNESSED this amplified fire work"

her lbrack tilde rbrack
"TRADITION TELLS US this water stabilizer is powerful"

inf lbrace asterisk plus tilde rbrace
"I INFER there must be steam based on the evidence"

int sac at
"I INTUITIVELY SENSE the sacred void's presence"
```

**Why it matters:** Changes the epistemic authority of the sigil!

### 2. ⏱️ ASPECT
**"How does this action unfold in time?"**

Inspired by: Russian, Greek, Swahili, Mandarin

Aspect is about the temporal STRUCTURE of an event - not when it happens (tense), but HOW it happens:

| Marker | Feature | Meaning | Real Language Example |
|--------|---------|---------|----------------------|
| `hab` | `aspect: habitual` | "Happens regularly/repeatedly" | Spanish imperfect |
| `perf` | `aspect: perfective` | "Completed, viewed as whole" | Russian perfective |
| `prog` | `aspect: progressive` | "Ongoing, in progress" | English -ing |
| `inch` | `aspect: inceptive` | "Just beginning" | Greek ἄρχομαι |
| `cess` | `aspect: cessative` | "Coming to an end" | Various languages |

**Examples:**
```
hab asterisk
"Fire that burns HABITUALLY/REGULARLY"

perf lbrace asterisk plus tilde rbrace
"A COMPLETED transformation into steam"

prog tilde
"Water that is CURRENTLY FLOWING"

"Air JUST BEGINNING to swirl"

"Earth that is CEASING to be solid"
```

**Why it matters:** Same element can have different temporal profiles!

### 8. 🔄 SWITCH-REFERENCE

| `ds` | `switch: different` | "Different subject" | Subject changed |
| `rfl` | `switch: reflexive` | "Acts on itself" | Reflexive action |

*Note: This feature is more relevant in multi-clause constructions*

**Examples:**
```

"Fire amplified, SAME FIRE amplified again"

ds asterisk tilde
"Fire acts, THEN WATER acts (different)"

rfl lbrace asterisk plus asterisk rbrace
"Fire acts upon ITSELF (reflexive)"
```

**Why it matters:** Tracks continuity of magical focus!

### 10. 👥 CLUSIVITY
**"Does 'we' include you?"**

Inspired by: Tok Pisin, Fijian, Cherokee, Quechua, many other languages

English has a bug: "we" is ambiguous! Many languages split it:

| Marker | Feature | Meaning | Who's Included? |
|--------|---------|---------|-----------------|
| `incl` | `clus: inclusive` | "We including you" | Speaker + listener(s) |
| `excl` | `clus: exclusive` | "We excluding you" | Speaker + others (not listener) |
| `solo` | `clus: solo` | "I alone" | Speaker only |

**Examples:**
```

"WE (including YOU) cast fire and water together"

excl asterisk hash
"WE (not you) cast fire and earth"

solo sac lbrace asterisk plus at rbrace
"I ALONE reverently fuse fire and void"
```

**Why it matters:** Changes participation and responsibility!

## Implementation Notes

### Feature Unification
The grammar uses treebender's feature unification to track all these properties:

```
AnnotatedContainer -> Evidential Container
```

This creates structures like:
```
Container[
  evid: direct          ← From evidential marker
  type: amplify         ← From container type
  energy: high          ← From element
  honor: humble         ← From honorific marker
  ...
]
```

### Ambiguity is a Feature!
Multiple parses are expected when features can attach at different levels:
```
vis hab asterisk
Could mean:
1. "I saw habitual fire" (both modify element)
2. "I habitually see fire" (hab modifies seeing)
3. "Visible habit of fire" (different parse entirely)
```

This is just like natural language ambiguity!

### Recursive Annotation
Annotations can stack:
```
rem sac vis nec hab hon spir sent updir cycdir <{...}>
```

Each adds meaning at a different layer of the semantic structure.
